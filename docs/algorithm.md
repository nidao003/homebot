# 算法说明

本文说明本工具「立极 → 八分法 → 归宫 → 星曜」每一步的做法、参数含义与已知局限。

> 传统堪舆经验体系的程序化实现，非科学定论。

---

## 1. 坐标与方位

### 1.1 图像坐标

一切计算都在**户型图原始像素坐标**下进行，y 轴向下（与图像一致）。
`poly` 里的点就是原图像素，不是缩放后的画布坐标。

### 1.2 真方位角换算

```
psi   = atan2(dx, -dy)          # 图像平面角：正上方 0°，正右 90°
theta = (theta0 + psi) mod 360  # 真方位角
```

`theta0` = **图像「正上方」对应的真实方位角**。

例：若户型图正上方实际朝东南（135°），则 `theta0 = 135`。

### 1.3 定向的坑

很多 CAD 导出的户型图上标的「N 朝上」是**错的**。真实朝向要靠：

- **主采光窗**所在的外墙方位
- 建筑外立面 / 单元门朝向
- 罗盘实测

`theta0` 错 45°，八个宫全部错位，结论全废。工具里做的是「把图旋转到你确认真实朝向」，
不是「相信图上的标注」。

## 2. 立极

**立极点** = 建筑主结构的中心太极点。
**立极框** = 主结构的外接矩形（`bounds_px`）。

### 2.1 悬挑构件不计入

阳台、雨棚、挑板、连廊等**悬挑构件通常不计入立极框**。

原因：这些构件面积大但结构上「挂」在主体上，计入会显著平移几何中心，
从而改变所有宫的判定结果（尤其是边缘房间的归属）。

> 实例：某户型若把阳台计入立极框，原本落在东北的大门会掉进震三，与人工实勘结论冲突。
> 这是「立极取主结构、不取悬挑」这一惯例的直接体现。

### 2.2 立极点怎么取

工具不做自动检测（自动检测建筑轮廓需要 CV，且户型图千差万别）。
实际操作是：**用户手点一个太极点**，再框一个立极矩形。两者独立：

- 立极点：影响**方位角**（所有射线从哪发出）
- 立极框：影响**米字格八分区的形状**（八分法的边界顶点）

两者可以不一致，工具不会强制对齐。

## 3. 八分法（米字格）

以立极中心为太极点，连接中心与立极矩形的：

- **四个角**：A(左上) B(右上) C(右下) D(左下)
- **四条边的中点**：N(上) E(右) S(下) W(左)

得到 8 个方向区，每区 = 中心 + 一角 + 一相邻半边：

```
(W,A) (A,N) (N,B) (B,E) (E,C) (C,S) (S,D) (D,W)
```

每个区的**角平分线**方位决定它属于哪一宫：

```
宫位 = PALACE_BY_BEARING[ floor(bisector / 45) mod 8 ]
     = [8, 3, 4, 9, 2, 7, 6, 1]
       艮  震  巽  离  坤  兑  乾  坎
```

对应关系（真方位角区间）：

| 区间 | 宫 | 卦 | 方位 |
|------|-----|-----|------|
| 315°–360° | 1 | 坎 | 正北 |
| 0°–45° | 8 | 艮 | 东北 |
| 45°–90° | 3 | 震 | 正东 |
| 90°–135° | 4 | 巽 | 东南 |
| 135°–180° | 9 | 离 | 正南 |
| 180°–225° | 2 | 坤 | 西南 |
| 225°–270° | 7 | 兑 | 正西 |
| 270°–315° | 6 | 乾 | 西北 |

### 3.1 为什么平分线是 22.5° + 45k

八区各含「一角 + 半边」，角与边中点的方位差 45°，平分线落在 22.5° 偏移处。
所以一个方向区（如坎）实际**覆盖 45° 的扇形**，而不是一个点。

## 4. 归宫

### 4.1 混合判定

对每个房间多边形 `P`：

1. 用 **Sutherland–Hodgman** 把 `P` 分别裁剪到 8 个方向区，算出重叠面积 `A_i`
2. 取 `share = max(A_i) / area(P)`
3. 若 `share >= SPLIT_THRESHOLD (0.45)` → 归入该区，标记 `by="overlap"`
4. 若 `share < 0.45` → 判为**跨宫**，改用房间**重心**的方位定宫，标记 `by="centroid"`

### 4.2 为什么要混合

两种方法各有硬伤：

| 方法 | 优点 | 硬伤 |
|------|------|------|
| **纯重心** | 简单、连续 | 边界房极敏感。一个横跨两条分界线的长条房，重心可能落在一个完全无关的角上 |
| **纯重叠** | 稳健、可解释 | 对凸形房偏保守，跨角的大房间会被硬切给某一角，且完全在立极框外的房间（阳台、玄关）无法判定 |

混合判定同时解决两件事：

- 框内房间 → 用重叠，结论可解释（能给出「该房 73% 在震三」）
- 框外房间（阳台/玄关/挑台） → 重叠全为 0，自动走重心兜底

### 4.3 `SPLIT_THRESHOLD` 的取值

0.45 是经验值：

- 阈值太低（0.3）→ 很多正常房间被判「跨宫」，报告里满屏跨宫提示，失去参考价值
- 阈值太高（0.6）→ 跨角房间被强行归一边，边界判断失真

调整入口：`src/bagua/core.py` 的 `SPLIT_THRESHOLD`，网页版同步改 `const SPLIT=`。
两侧有测试保证一致（`test_split_threshold_matches_python`）。

### 4.4 已知局限（重要）

**米字格 + 质心混合法在真实户型上的准确率约 7/7（有条件）**，
但这个数字**依赖特定朝向区间**。

在一套真实户型（立极中心 `(632, 438.5)`、立极框 `x292-972 / y203-674`）上扫描 `theta0`：

| 方法 | 命中 |
|------|------|
| 米字格纯重叠 | `theta0 ∈ [30°, 50°]` 达 7/7；`theta0 = 30/45/60` 只得 6/7；`theta0 = 90/120/180/225/270/315` 得 0/7 |
| 纯质心 | `theta0 ∈ [30.5°, 36.0°]` 达 7/7；`theta0 = 45°` 时某卧判为乾六（真值兑七） |

结论：

- **米字格法对 `theta0` 敏感**，`theta0` 偏离真实值 30° 以上就可能连环错位
- **质心法在窄区间内非常准**，但区间宽度只有 ~5.5°，实用上太脆
- 两者**没有哪个是自证的 8/8**

> ⚠️ 早期版本宣传的「八分法 8/8 全中」是**手绘版**基于
> 「4 角 = 坎震离兑、4 边中 = 艮巽坤乾」这一**启发式**得出的，
> **不是**多边形裁剪算法的输出。两者结论在多数户型上一致，但不能互相背书。
> 本文档记录该差异，避免后来者把 8/8 当作算法正确性的证据。

### 4.5 实践建议

1. **先定 `theta0`**，用主采光窗 / 外立面确认，别信图上标注
2. `theta0` 定好后，对比工具给的每房「占比」和「跨宫」标记
3. 占比特别低（< 0.5）且标记跨宫的房间，**人工复核**——这通常是立极框画歪了
4. 全屋都判跨宫 → 立极框或立极点画错了，回去调
5. 门所在宫单独看（门位口径），别和宅卦口径混用

## 5. 星曜

### 5.1 表

传统八宅大游年星曜表，`BAZHAI_STARS[伏位宫][该宫] = 星名`：

- 8 个伏位宫 × 8 个目标宫 = 64 格
- 每行 8 个星名互不重复，且恰好 4 吉 4 凶
- 每行自己的位置必为「伏位」

测试 `test_each_row_has_8_distinct_stars` / `test_fuwei_star_is_at_own_palace` 全量对账。

### 5.2 吉凶

| 吉（4） | 凶（4） |
|---------|--------|
| 伏位、生气、延年、天医 | 祸害、五鬼、六煞、绝命 |

### 5.3 三套口径

同一张表，三种伏位定义。**不可混用**：

| 口径 | 伏位 = | 关注点 |
|------|--------|--------|
| 宅卦（八宅） | 坐山宫 | 房子本身的格局 |
| 门位（大游年） | 大门所在宫 | 动线、气口 |
| 命卦 | 命卦宫 | 个人的用神落位 |

命卦分组：**东四命** = 坎离震巽（1,3,4,9）；**西四命** = 乾坤艮兑（2,6,7,8）。

报告里三套口径**分列**，不合成单一结论。

### 5.4 由坐山定宅卦

24 山 → 宫位（`SHAN_TO_GUA`）：

| 宫 | 山 |
|----|-----|
| 坎一 | 壬 子 癸 |
| 艮八 | 丑 艮 寅 |
| 震三 | 甲 卯 乙 |
| 巽四 | 辰 巽 巳 |
| 离九 | 丙 午 丁 |
| 坤二 | 未 坤 申 |
| 兑七 | 庚 酉 辛 |
| 乾六 | 戌 乾 亥 |

### 5.5 两套口径的常见误用

「宅卦乾六 → 伏位在乾六」和「门在艮八 → 伏位在艮八」是**两回事**。
前者是八宅格局，后者是大游年。两者对同一房间会给出不同星名，**都可能是对的**。
工具把两列并排显示（`宅卦` / `门位`），不替使用者合并。

## 6. 渲染

`src/bagua/svg.py` 输出黑金风格 SVG（纯标准库，无第三方依赖）：

- 底图（可选，`<image>` 内嵌）
- 米字格 8 分区（吉=金 / 凶=红，14% 透明）
- 房间多边形 + 名称 + 宫位 + 宅卦星 + 各命卦星
- 卦象徽标沿射线贴边排布
- 罗盘（24 山刻度）
- 八宫星曜表（右栏）
- 房间 × 命卦对照表
- 页脚免责声明

### 6.1 SVG 踩坑

- **缩放组内 `stroke-width` 的单位是 mm**（SVG 规范），写 `7` 在缩放后可能变成 0.6px。
  做法：把需要的线宽乘上缩放比，或干脆不缩放组、改用 `vector-effect="non-scaling-stroke"`。
- **`marker` 默认按线宽缩放**，箭头会大小不一。做法：不用 marker，手工画三角。
- **`<g transform="rotate">` 里的竖排文字容易错位**。做法：把旋转算进坐标，不靠 transform。
